# SheGuardian – Women's Safety App

**SheGuardian** is a mobile application focused on women's safety, offering real-time, location-based emergency support through a volunteer network and automated alert systems. The app uses GPS tracking, SOS alerts, live location sharing, and direct police/helpline integration to reduce response time and ensure rapid assistance. It employs geo-indexing (Haversine + Geohash) and a dual notification system (FCM + SMS), making it reliable even in low-connectivity areas.

## 🚀 Features

- 🔴 One-tap SOS alert system
- 📍 Real-time GPS tracking
- 🧭 Route safety recommendations
- 🛡️ Community-driven volunteer response
- 📲 Live location sharing
- 📞 Direct helpline and police integration
- 📊 Safety data for policy planning
